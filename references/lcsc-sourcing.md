# LCSC / 嘉立创 器件选型

原则：**能买到 > 参数最优**。贴片订单里买不到的料等于没有。

## 1. 嘉立创贴片库三类

| 类型 | 贴片附加费 | 说明 |
|---|---|---|
| **基础库** | 无附加费 | 首选。约 2 万种常用料 |
| **扩展库** | 约 ¥3/件附加费 | 大部分料在这里，可用但贵 |
| **优选库** | 基础库子集 | 深圳仓有现货，贴片更快 |

**选型顺序**：先基础库 → 再优选 → 最后扩展库。每个非基础库器件在 BOM 中标注附加费影响。

## 2. 必查字段

- **LCSC C 编号**（如 `C6186`）——唯一可信的器件身份标识
- **封装**：与焊盘一致；注意同名封装不同尺寸（如 SOT-23-3 vs SOT-23-5）
- **SMT 是否支持**：必须可贴片才能走贴片
- **库存状态**：缺货/预售料不进量产 BOM
- **电压/电流/温度等级**：与设计裕度核对，不留 0 裕度
- **价格阶梯**：按实际数量核算，不是 1 片价

## 3. 常见封装手工焊接友好度

| 封装 | 手焊难度 | 建议 |
|---|---|---|
| 0603 / 0805 | 容易 | 阻容首选 |
| 1206 / 1210 | 容易 | 功率电阻 |
| SOP-8 / SOP-16 | 容易 | 常用驱动/LDO |
| SOIC-8-EP（含散热焊盘） | 中等 | 需注意 EP 焊盘走热 |
| TQFP/LQFP | 较难 | 有引线的多脚芯片，需拖焊或热风 |
| QFN / BGA | 难 | 打样阶段尽量避开；必要时选带引线的 LQFP 替代 |
| 0402 及以下 | 难 | 不手焊时可用 |

## 4. 常用料速查（**必须现查确认，下表仅为示例，可能已失效**）

```
| 位号 | 型号 | 封装 | LCSC C号 | 单价 | 库存 | 验证状态 |
|------|------|------|----------|------|------|----------|
| R1   | 10kΩ 1% | 0603 | C25804 | - | - | 已核实 |
| C1   | 100nF 50V | 0603 | C14663 | - | - | 已核实 |
| U1   | AMS1117-3.3 | SOT-223 | C6186 | - | - | 已核实 |
```

## 5. 电源类器件选型要点

- **输入电压范围**：按最坏情况（电池满电、适配器上限）核对
- **峰值电流**：按所有负载同时拉载的最大值，不是平均电流
- **压差与效率**：LDO 关注 dropout；DC-DC 关注效率与开关频率
- **热耗**：`pcbcalc.py thermal-ldo` 估算结温，留 ≥20°C 裕度
- **反馈分压**：按数据手册公式算，用 `pcbcalc.py divider` 复核
- **使能与时序**：多电源域的上电顺序要显式设计，不能指望巧合

## 6. 连接器选型要点

- **间距**：2.54mm 排母/排针手焊友好；1.27mm 需对准
- **牛角座（盒式 Header）**：带护套、有定位方向，防反插。2×N 时注意 Pin-1 标识
- **电流能力**：大电流（电机、舵机电源）不要走信号排针，用专用端子或螺丝座
- **机械强度**：对外接口需考虑插拔力，必要时加固或选带固定耳的座子
- **方向标识**：丝印必须标出 Pin-1 与接口名

## 7. 建库

若官方库与 LCSC 都没有匹配器件，按数据手册建库：

1. 先 `component_select` / `library_search` 搜 C 号与型号，确认真的没有
2. 通读数据手册：订购后缀、引脚表、封装尺寸图、推荐焊盘
3. 创建 Symbol → Footprint → Device，**保留证据页码**
4. 用离线规格校验（几何 + 引脚映射）后再写入
5. 回读 pin↔pad 映射，放置一个实例检查 Pin-1 位置
6. 只有手册确实存在多个无法消歧的封装、或缺少关键尺寸时才问用户

**核心板/模组建库必须实测**：尺寸、孔位、孔径、焊盘直径与钻孔直径一律实测，
不要照抄商品图片。参考案例：某 STM32F407 核心板实测
74.07 × 43.59 mm，焊盘 Ø1.60 mm / 钻孔 Ø1.05 mm，M3 安装孔距 49.1 × 26.5 mm。
