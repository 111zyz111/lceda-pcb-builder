# Gate 1：需求 intake

目标是把「一句话需求」拆成「能画的信息」+「必须问的阻塞项」+「可以按假设继续的非阻塞项」。
**不要一上来就画图。**

## 1. 分类原则

| 类别 | 判定标准 | 处理方式 |
|---|---|---|
| **阻塞项** | 影响架构、拓扑、层数、尺寸、供电方式，猜错会导致整板返工 | **先问**，同时推进不依赖答案的工作 |
| **可假设项** | 只影响局部取值或可后调 | 标注保守假设并继续，在设计说明中列出 |

阻塞项太多时合并成一次问完，不要连环追问。

## 2. 必问清单（阻塞项候选）

按优先级排列，命中就问：

1. **板尺寸与形状**：长×宽（mm）、圆角、安装孔位与孔径（M3? M2?）、是否需避开某区域
2. **层数**：2 层 / 4 层 / 6 层；4 层是否要内电层；叠层由谁定（自己 / 厂方默认）
3. **供电**：输入电压范围或电池节数（几 S 锂电？）、总峰值电流、
   是否需要独立电源轨（如舵机 VSERVO 与大电流负载）
4. **接口清单**：每个接口的型号/引脚数/方向（USB、串口、SWD、CAN、以太网、
   摄像头排线、电机端子、舵机 3pin…）与对外连接器形式
5. **MCU / 主芯片**：型号、封装、是否已有核心板、核心板是否引出全部所需引脚
6. **工作环境**：温度范围、湿度、振动、防水、电磁环境
7. **数量与成本**：打样几块 / 小批量；是否必须走贴片（SMT）还是允许手焊
8. **认证与可靠性**：是否需要过 CE/FCC、车载、医疗
9. **投板厂**：嘉立创 / PCBWay / 其他；是否贴片；层数/工艺档位

## 3. 常见但**不必**问的（按保守假设继续）

- 去耦电容数量与容值（按每电源域 100nF + 若干 μF 起步）
- 上拉电阻取值（I²C 默认 4.7kΩ，标注假设）
- 测试点位置（先按接口就近，后调）
- 丝印字号（默认 1.0mm 高，避开焊盘）
- 线宽（按 `pcbcalc.py` 计算值 + 厂方工艺下限取大者）

## 4. 核心板 / 模组的特殊陷阱

若用户提供的是**已有核心板**（如 STM32 核心板、ESP32 模组、摄像头模组），必须逐脚核对：

- [ ] 核心板的排母引脚是否**全部引出**所需 MCU 信号？常见坑：
      SWD（PA13/PA14）、NRST、USB D+/D−、某些定时器通道**未焊到排母**。
      例：某 STM32F407 核心板的 116 脚排母不含 PA13/PA14/NRST，
      导致 ST-Link 必须飞线到核心板自带 SWD 座，不能走排母。
- [ ] 核心板 5V 脚是**输入**还是**输出**？与外部 5V 或 USB 供电是否冲突？
- [ ] 核心板工作电压域与底板外设电压域是否一致（3.3V / 5V 混接要电平转换）？
- [ ] 核心板安装孔位与孔径、板厚、限高区是否与底板兼容？
- [ ] 核心板已带晶振 / 已带 LDO 的，底板上不要重复提供。

## 5. 输出模板

见 [templates/design-brief.md](../templates/design-brief.md)。产出后必须包含：

```
## 阻塞项（待用户答复）
## 保守假设（已按此继续）
## 功能方块图（文本或 ASCII）
## 电源树草案（输入 → 各级变换 → 各负载域）
```

## 6. 放行条件

阻塞项全部答复，或用户明确说「按假设继续」。否则停在 Gate 1，
但可以并行做：数据手册检索、候选器件比选、核心板尺寸实测。
