# MCU 引脚分配约束

引脚分配是原理图阶段最容易返工的地方。**先分配引脚，再画图。**

## 1. 通用分配流程

1. 列出所有外设需求（接口 × 数量）
2. 查 MCU 数据手册的**复用功能表**，找出每个功能可用的引脚集合
3. 先分配**有硬约束**的（专用引脚、只能某定时器的通道）
4. 再分配**软约束**的（普通 GPIO、软件模拟接口）
5. 检查冲突：同一引脚不能被两个功能占用；同一定时器不同通道不要随便拆
6. 输出引脚分配表，标注每个引脚的功能与来源（数据手册章节）

## 2. 硬约束类（必须先分配）

| 类型 | 硬约束 |
|---|---|
| 晶振 | OSC_IN/OSC_OUT 固定引脚 |
| 启动配置 | BOOT0/BOOT1 必须按启动方式接 |
| SWD | SWDIO/SWCLK 固定；**注意核心板是否引出** |
| NRST | 复位脚；是否上拉、是否需外接复位电路 |
| USB | D+/D− 固定引脚 |
| ADC | 只能 ADC 通道；模拟供电与参考电压独立 |
| 专用定时器通道 | 如电机 PWM 需要互补/死区时只能用高级定时器 |

## 3. 常见 STM32F4 系列要点（示例，须以具体型号数据手册为准）

- **定时器**：TIM1/TIM8 是高级定时器（互补输出、死区、刹车），适合电机；
  TIM2/TIM5 是 32 位；TIM3/TIM4 是通用 16 位
- **舵机 PWM**：20 ms 周期、1–2 ms 脉宽，任一通用定时器通道即可
- **电机 PWM 频率**：通常 10–20 kHz，避开音频段
- **USART**：USART1 通常 APB2，其余 APB1，注意时钟树
- **SPI/I²C**：复用引脚有限，多路外设要排
- **FSMC**：接并口 LCD / SRAM / FIFO 类器件时占用一整组引脚，要提前规划
- **ADC 注入/规则**：多通道采样要注意触发源与转换时间

## 4. 引脚分配表模板

```
| 引脚 | 功能 | 外设 | 来源(数据手册章节) | 备注 |
|------|------|------|-------------------|------|
| PA8  | TIM1_CH1 | 电机A PWM | Table 9 | 高级定时器 |
| PC1  | ADC123_IN11 | 电流采样 | Table 9 | 12位 |
| PA13 | SWDIO | ST-Link | Table 9 | 核心板未引出→飞线 |
```

## 5. 冲突检查清单

- [ ] 同一引脚无重复分配
- [ ] 电源脚全部接对应域，且每个域都有去耦
- [ ] ADC 脚未用作数字高速信号（避免串扰）
- [ ] 未用脚要么接固定电平（上拉/下拉）、要么标 NC，不要悬空
- [ ] 5V 容忍脚（FT）与普通脚区分清楚
- [ ] 复位与启动脚的上拉/下拉正确

## 6. 核心板引出的陷阱（务必逐脚核对）

核心板的排母往往**不引出**以下脚，或引出但被板载器件占用：

- SWDIO / SWCLK / NRST
- USB D+ / D−
- BOOT0
- 部分定时器通道、部分 ADC 通道
- 部分 GPIO 被板载 LED/按键占用

核对方式：读核心板的原理图或封装图，或实测。**不要假设"F407 有 100 多个脚所以肯定都引出了"。**
