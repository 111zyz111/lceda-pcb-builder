# PCB 规则：布局、布线、叠层、铺铜、丝印

## 1. 板框与层叠

- 板框放在机械层（嘉立创专业版 PCB 中固定用层 11）
- 圆角半径按厂方工艺下限（通常 R ≥ 1.0 mm），避免尖角
- 层数先定，再布局。改层数前先确认内层无图元
- 叠层（4 层常用）：

| 层 | 用途 | 说明 |
|---|---|---|
| Top | 信号 + 元件 | 主要走线 |
| GND | 完整地平面 | 不要切碎 |
| PWR | 电源平面 / 分割 | 也可作第二信号层 |
| Bottom | 信号 + 元件 | 次要走线、大电流 |

> 叠层最终以厂方默认或用户指定为准，本表是常见起点。

## 2. 布局顺序（不要跳步）

1. **连接器与机械约束**先定：对外接口靠边、朝外，插拔方向不挡其他器件
2. **安装孔**：按实测孔位，孔径比螺丝大 0.2–0.4 mm；孔壁到铜留间距
3. **电源电路**：输入端子 → 保护 → DC-DC/LDO，按电流方向排
4. **发热与功率器件**：远离热敏感器件，靠近板边或散热区
5. **时钟与晶振**：远离连接器与板边，走线最短
6. **敏感模拟**：远离开关电源与数字高频
7. **高速信号**：缩短、等长、有连续地回流
8. **大电流路径**：短而粗，多用过孔并联
9. **测试点**：最后加，放在好探的位置

## 3. 分区原则

- 按功能分区，每个区一个主要器件 + 其阻容
- 功率地与数字地分开铺，最后单点连接
- 禁止把不同电压域的器件混放在一起还不做隔离
- 天线/射频区域全层 keepout

## 4. 布线

- 线宽按 `pcbcalc.py trace` 计算结果 + 厂方工艺下限，取大者
- 电源与地先布，且尽量粗
- 高速/时钟线：短、直、有地回流、避免跨地平面分割
- 差分对：等长、等距、同层
- 过孔数量与尺寸按载流核算，大电流用多过孔并联
- 禁止锐角走线；45° 或圆角
- 同一网络的走线宽度不要无故变化

## 5. 铺铜

- 地铺铜优先，Top/Bottom 都铺，用 Via 缝合到地平面
- 铺铜与焊盘/过孔间距按厂方规则
- 功率区铺铜辅助散热，铜下加散热过孔
- 铺铜后必须显式重建，回读确认生效

## 6. 丝印

- 每个器件位号可读，不压焊盘、不出板框、不重叠
- 接口必须标名字与方向（Pin-1 点标）
- LED 标极性；电解电容标正负
- 底层丝印要镜像
- Logo 用矢量，不要位图
- 丝印不能进焊盘（影响焊接与 AOI）

## 7. DRC

PCB DRC 必须无 error 才进 Gate 5。常见 error 类：

- 走线到走线 / 走线到焊盘间距不足
- 丝印压焊盘
- 出板框
- 未连接网络
- 内电层间距
- 焊盘尺寸低于工艺下限

DRC 详情可能分页，必须翻完所有页再下结论。

## 8. 散热

- LDO / DC-DC / 功率管的结温用 `pcbcalc.py thermal-ldo` 或 `thermal-shunt` 估算
- EP 焊盘（如 SOP-8-EP）必须打过孔到内层或底层铜散热
- 结温裕度不足 → 换器件、加铜、加散热孔，不要硬扛
- 电解/钽电容远离热点
