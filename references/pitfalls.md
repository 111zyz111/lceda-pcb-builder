# 已知坑清单

这些坑来自实测与开源项目记录，**每次画板前扫一遍**。

## 1. 坐标与格式类

| 坑 | 后果 | 规避 |
|---|---|---|
| **Y 轴方向不一致** | `.kicad_sym` 符号库 Y 向上；`.kicad_sch` 原理图与 `.kicad_pcb` Y 向下。从库空间转到原理图空间**必须对 Y 取负** | 转换时统一做 `y = -y`，写单元测试验证一个已知引脚位置 |
| **嘉立创同名图元跨文档歧义** | `LINE` 在 SCH_PAGE 是导线、在 PCB 是走线，schema 不同 | 校验时用 `PCB_LINE` 前缀名或 `--doc PCB` |
| **嘉立创行数据格式** | 每行 `{type, id, ticket}\|\|{data}`；文档以 `DOCHEAD` 开头，仅含画布的文档类型（SCH_PAGE/SYMBOL/SIMULATION/PCB/FOOTPRINT/PANEL/PANEL_LIB）才有 `CANVAS` 行 | 生成时按官方 `easyeda-format-skill` 的规则走，并跑 `validate.js` |
| **Protel ASCII 单位是 mil** | `.schdoc`/`.pcbdoc` 坐标 1 mil = 0.0254 mm，当 mm 会差 25.4 倍 | 解析时先看 HEADER，统一换算 |
| **原生坐标归一化** | 嘉立创创建轮廓时会把坐标归一化到四位小数，反向绕序与循环起点可变 | 回读比对归一化结果，不要按原始输入逐字符比较 |

## 2. 核心板 / 模组类

| 坑 | 后果 | 规避 |
|---|---|---|
| **以为排母引出全部引脚** | SWD/NRST/USD D+D− 常未引出，导致飞线或功能缺失 | 逐脚核对，见 intake.md §4 |
| **核心板 5V 脚方向不明** | 与外部 5V 或 USB 供电冲突，可能倒灌 | 问清是输入还是输出 |
| **模组已带晶振仍供时钟** | 多时钟源冲突 | 读模组图 |
| **模组已带 LDO 仍外供** | 双 LDO 倒灌或过压 | 读模组图 |
| **照抄商品图片尺寸** | 封装尺寸错，装不上 | 实测 |

## 3. 电源类

| 坑 | 后果 | 规避 |
|---|---|---|
| 大电流（电机/多舵机）与信号共用排针 | 压降、发热、信号受扰 | 独立端子 + 独立 `VSERVO` 轨 |
| 舵机与大功率负载共用同一 5V 轨 | 堵转时拉垮 MCU 供电，死机重启 | 独立电源轨 + 分开的电流路径 |
| 省 LDO 输入/输出电容 | 振荡、不稳 | 按数据手册最小值取 |
| 忽略反接与浪涌 | 上电即炸 | 反接保护 + 保险丝 + TVS |
| 反馈分压算错 | 输出电压错，烧后级 | `pcbcalc.py divider` 复核 |

## 4. 驱动类

| 坑 | 后果 | 规避 |
|---|---|---|
| H 桥 EP 散热焊盘不接 | 过热保护或烧毁 | EP 打过孔到内层铜 |
| ISEN 采样电阻取值未算 | 限流值与预期不符 | 按数据手册公式 + 脚本复核 |
| 忽略反电动势 | 电机停转时高压回灌 | 续流路径 + TVS |
| PWM 频率选在音频段 | 啸叫 | 10–20 kHz 起步 |

## 5. 数据手册类

| 坑 | 后果 | 规避 |
|---|---|---|
| 引脚名相似但不同（如 EN/ENB、SDA/SDIO） | 接错 | 以引脚表 + 功能描述为准，不要只看名字 |
| 同名封装不同尺寸（SOT-23-3 vs -5） | 装不上 | 核对封装编号与尺寸图 |
| 绝对最大值当工作值 | 寿命骤降 | 留裕度，查 recommended 表 |
| 引脚顺序按"直觉"排 | 镜像错 | 按尺寸图 + Pin-1 标记核对 |

## 6. 交付类

| 坑 | 后果 | 规避 |
|---|---|---|
| 只看 EDA 视图目视复核 | 导出设置错误没发现 | 用独立 Gerber 查看器打开导出的文件 |
| DRC 只看第一页 | 漏掉后页 error | 分页必须翻完 |
| BOM 与 CPL 位号不一致 | 贴片厂无法贴 | `bom_check.py` 对账 |
| 板框层选错或未导出 | 厂方按默认尺寸切 | 板框独立层 + 目视复核 |

## 7. AI 画板特有坑

| 坑 | 后果 | 规避 |
|---|---|---|
| **凭截图猜连接** | 全错且难以发现 | 只信读到的真实数据 |
| **凭记忆编料号/引脚** | 假数据进 BOM | 现查，查不到标「待核实」 |
| **写入不回读** | 静默失败，后面对账全线崩 | 每个写操作后回读 |
| **多页面选错目标** | 改到别的工程 | `bridge_clients` + `bridge_select_client` 先行 |
| **心算线宽/分压** | 数值错 | 一律跑 `pcbcalc.py` |
