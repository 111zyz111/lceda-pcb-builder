# 原理图规则

## 1. 命名约定

| 对象 | 规则 | 示例 |
|---|---|---|
| 电源网络 | `+3V3`、`+5V`、`VBAT`、`VSERVO` | 独立电源轨必须有独立名字 |
| 地 | `GND`（数字地）、`GNDA`（模拟地）、`PGND`（功率地） | 单点连接，不随便合并 |
| 信号 | 大写 + 下划线，含来源或用途 | `OV_SCL`、`FIFO_D0`、`MOTOR_IN1` |
| 排母引脚 | `J<数字>` 位号，Pin-1 标注 | `J1` |
| 跨页连接 | 用跨页连接标识，不要靠视觉对齐 | 同网络名 |

**禁止**：`NET1`、`N0001` 之类的默认名进交付；`NC` 必须显式标注而非留空。

## 2. 位号分配

- 按功能分区连续分配（电源 R1-R9、U1-U3；接口 J1-J6；信号 R10 起）
- 已有器件替换时**保留原有位号**，便于对账
- 同一功能块的器件位号相邻，便于后期找板

## 3. 电源与去耦

- 每个电源域至少一个 100nF 靠近芯片电源脚；功耗大的加 1–10μF
- LDO 输入输出电容按数据手册最小值取，不要省
- 大电流路径（电机、舵机电源）**不要与信号共用排针**，用独立端子
- 独立电源轨（如 `VSERVO`）在电源树中单独画出来，并说明为什么独立
- 反接保护、保险丝、TVS 的位置要显式，不能省略

## 4. 常见接口连接要点

### 串口 / USB 转 TTL
- TX/RX 交叉对接，确认双方电平域（3.3V vs 5V）
- 若对方是 USB 转串芯片，保留其自动下载电路（如 ESP32 的 EN/IO0）
- 保留硬件握手脚或至少引出 RTS/DTR

### ST-Link / SWD
- SWDIO / SWCLK / NRST / GND 四线
- SWDIO 与 SWCLK 需上拉（部分目标必需）
- **确认目标板是否真正引出这些脚**（见 intake.md §4）
- 若只能飞线，在原理图中画一个「飞线到核心板 SWD 座」的明确注释

### 舵机
- 三线：信号 / +5V / GND；信号通常接定时器 PWM 通道
- 多个舵机共用电源时要核算总电流；大数量舵机用独立 `VSERVO` 轨
- 信号串 100Ω 左右限流可选，地线要粗

### 电机驱动（H 桥，如 AT8236）
- IN1/IN2 双 PWM 控制方向与调速
- VM 电源、VREF、ISEN（电流采样）、OUT1/OUT2 与散热焊盘 EP 全部接对
- ISEN 采样电阻取值按数据手册与期望限流值计算，用 `pcbcalc.py` 复核
- 电源与地之间加储能电容，靠近 VM 脚
- 反电动势保护：续流二极管或芯片内置；对外接口加 TVS

### 摄像头（OV7670 + AL422B FIFO 类）
- 模组自带晶振时 **不需要** 供 XCLK/PCLK，读取用 RCLK 选通
- 数据线常为交错排列：D0/D2/D4/D6 一组、D1/D3/D5/D7 一组，按模组图接，不要按顺序臆测
- 控制线（SCCB/I²C：SCL/SDA）需上拉
- FIFO 控制：WRST / RRST / WEN / OE / RCLK 全部接 MCU
- VSYNC / HSYNC 中断或查询

## 5. ERC / DRC 检查点

原理图 DRC 必须无 error 才进 Gate 4。重点看：

- [ ] 单端网络（某引脚没接）
- [ ] 多驱动（两个输出短在一起）
- [ ] 电源与地短路
- [ ] 引脚类型冲突（输出接输出）
- [ ] 网络标签拼写不一致导致的假悬空
- [ ] 未标注的 NC 引脚

## 6. 自检

Gate 3 放行前运行：

```bash
python scripts/netlist_check.py <net-table.csv> <原理图导出的网表>
```

必须 0 差异。有差异先查是不是命名/位号问题，再查是不是真接错。
